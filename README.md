### 🚀 About Me

Hey! I’m **Abraz**, a **Data Engineer** at **Standard Chartered GBS** (Chennai, India) working within the **HANA Cloud — Finsight Client MI** team. I focus on building reliable, high-throughput enterprise data pipelines and exploring practical AI-driven tooling.

- 🎓 **Education:** B.Tech in Computer Science · VIT-AP University (8.61 CGPA)
- 🏢 **Current Work @ Standard Chartered GBS:**
  - Architecting **config-driven ingestion pipelines** spanning **40+ countries** and **5 distinct source systems** on SAP HANA Cloud + BTP.
  - Designing a **centralized logging & observability framework** to monitor pipeline reliability, telemetry, and data quality in real time.
- 🤖 **On the Side:** Building AI agents, LLM applications (Claude, Gemini 2.0), and developer tools.
- 🎯 **Looking For:** Actively open to full-time opportunities in **Data Engineering** & **AI / ML Engineering**.
